# Trader's Journal

A browser-based trading journal built with React, TypeScript, and Vite.

## Data and backups

Trades, screenshots, settings, and journal preferences stay in the current browser's local storage. They are not uploaded to GitHub or synchronized between browsers. Use **Settings → Profile → Journal data** to download a backup before moving to another browser or the GitHub Pages site, then restore that file there.

The public app will be available at <https://imammutaqin211.github.io/journal-trader/> after the first successful GitHub Pages deployment.

## Development

```sh
cd app
npm ci
npm run dev
```
